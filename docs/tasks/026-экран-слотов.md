# 026. Экран слотов

Срез: Админка

Зависит от: 014, 025

## Зачем

Воскресная тренировка и вторая тренировка в неделе заводятся без деплоя.

## Готово, когда

Есть слот воскресенье 17:00, зал подставлен, часы автоматизации видны и сохраняются.

## Шаги

1. API слотов.
2. Форма: зал, день недели, время начала, действует с, действует до, замена минимума. Поля дежурного и режима нет.
3. Если замена минимума пустая, показывать минимум зала и писать, что действует он.
4. Часы пяти моментов автоматизации. Подписи по-русски, как в дизайне.
5. Валидация: действует до не раньше действует с.

## Проверить

Слот читается из API после сохранения с телефона.
