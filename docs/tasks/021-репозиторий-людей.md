# 021. Репозиторий людей

Срез: API

Зависит от: 013, 009

## Зачем

Админка и бот читают людей через один слой, не через SQL в обработчиках.

## Готово, когда

Есть функции: список, карточка, создать, изменить ник, статус, плательщика, телефон, роль, депозит. Тест на запрет плательщика-самого-себя.

## Шаги

1. Пакет `internal/store` на pgx.
2. Смена статуса с новичка на другой не обнуляет newcomer_visits: счётчик остаётся историей. Возврат в новичка не сбрасывает счётчик до нуля, следующие бесплатные явки снова его увеличивают. Зафиксировать это в комментарии к функции.
3. Депозит: установить баланс. Отрицательный баланс не сохранять.
4. Список людей отдаёт флаг «пора сменить статус», если status=newcomer и newcomer_visits >= настройки клуба.

## Проверить

Юнит или интеграционный тест на postgres из compose покрывает смену статуса и депозит.
