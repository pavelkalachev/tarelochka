# 020. Первый организатор и клуб

Срез: Данные

Зависит от: 013, 019

## Зачем

Без первой роли в админку никто не войдёт.

## Готово, когда

После миграции в базе одна строка клуба. Человек с ником из переменной `FIRST_ORGANIZER_USERNAME` помечен is_organizer.

## Шаги

1. Переменная `FIRST_ORGANIZER_USERNAME` без `@`.
2. Если человека с таким ником ещё нет среди 19, не создавать дубль наугад. Паша уже есть в шапке: ник записать ему.
3. Команда сида отдельно от импорта таблицы, чтобы ник можно было проставить повторно без повторного переноса сумм.
4. В README написать, что ник должен совпасть с нажатиями в Telegram. На локальном прогоне это ник того, кто жмёт кнопки в тестовом чате. Ники всего клуба вносят на задаче 048, уже на боевой базе.

## Проверить

В базе ровно один организатор, у него записан ник.
