# 043. Списание депозита

Срез: Деньги

Зависит от: 039, 040

## Зачем

Депозит Дениса закрывает целые доли его и Вики до сообщения в чат.

## Готово, когда

При зале, где доли Дениса и Вики по 614, а депозит 4500, обе доли paid via deposit, баланс 4500-1228. Если баланса хватает только на одну, закрыта доля Дениса, доля Вики unpaid, баланс уменьшен на одну долю. Доля 700 при балансе 600 не списывается вообще.

## Шаги

1. Вызвать после записи shares и до debt message.
2. Для каждого депозита найти человека и тех, за кого он платит.
3. Сначала его собственная доля, потом доли подопечных по имени шапки, стабильный порядок.
4. Списывать только если balance >= amount и amount > 0. Ноль новичка не трогать.
5. Статус paid, paid_via deposit.
6. Повторный confirm не списывает вторую раз уже оплаченную долю.
7. В сообщении долга этих долей нет.
8. Экран депозита показывает новый баланс.

## Проверить

Три теста из раздела «Готово, когда» автоматические.
