# 011. Один compose для локальной разработки

Срез: Каркас

Зависит от: 008, 009, 010

## Зачем

Разработчик поднимает базу и смотрит админку одной инструкцией.

## Готово, когда

README говорит: `make db`, `make run`, `make web`. Health и страница Vite открываются.

## Шаги

1. Не собирать фронт внутрь Go на этом шаге. Vite проксирует `/api` на Go, когда API появится.
2. Прописать proxy в `vite.config.ts` на адрес Go.
3. Проверить, что оба процесса стартуют из README без правок кода.

## Проверить

Новый клон по README доходит до health и пустой страницы, если заполнен `.env`.
