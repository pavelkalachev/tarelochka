# 002. Добавить бота в чат

Срез: Подготовка

Зависит от: 001

## Зачем

Опросы и долги живут в чате «Алтимат. Челябинск».

## Готово, когда

Бот состоит в чате. Он может писать сообщения. Тестовое сообщение от бота в чате видно участникам и затем удалено.

## Шаги

1. Открыть чат «Алтимат. Челябинск».
2. Добавить бота из задачи 001.
3. Выдать боту право писать сообщения. Право закреплять сообщения не требуется: опрос не закрепляем.
4. Узнать id чата. Пока сервера нет, это можно сделать временным локальным скриптом `getUpdates` после любого сообщения в чате, где бот его видит, либо позже на задаче 032. Id чата отрицательный, для супергруппы обычно начинается с `-100`.
5. Записать id чата рядом с токеном, не в git.
6. Не оставлять в чате отладочный мусор.

## Проверить

Бот есть в списке участников. В заметке запуска есть id чата.
