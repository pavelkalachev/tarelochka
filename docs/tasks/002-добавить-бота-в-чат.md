# 002. Свой тестовый чат

Срез: Локальная разработка

Зависит от: 001

## Зачем

Опросы, кнопки и долги нужно видеть вживую до чата клуба. Для этого хватает закрытой группы, в которой есть разработчик и тестовый бот.

## Готово, когда

Тестовый бот состоит в отдельной группе. Он может писать сообщения. Id группы записан рядом с токеном, не в git. Чат «Алтимат. Челябинск» не использовался.

## Шаги

1. Создать новую группу. Название должно отличаться от чата клуба.
2. Добавить в неё только тех, кто отлаживает, и бота из задачи 001.
3. Выдать боту право писать сообщения. Право закреплять сообщения не требуется.
4. Узнать id чата локальным `getUpdates` после любого сообщения в этой группе. Id отрицательный, для супергруппы обычно начинается с `-100`.
5. Записать id рядом с токеном тестового бота, не в git.
6. Тестовое сообщение бота удалить. В чате клуба сообщений не оставлять: бота там нет.

## Проверить

Бот есть в списке участников тестовой группы и отсутствует в чате клуба. В заметке есть id тестового чата.
