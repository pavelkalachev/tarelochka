# 047. Боевой перенос таблицы

Срез: Публикация

Зависит от: 019, 046, 005

## Зачем

История сезона оказывается в боевой базе один раз. Та же команда уже прошла на локальной базе в задаче 019.

## Готово, когда

На сервере 19 людей, 48 тренировок, депозит 4500, пары Вика–Денис и Лена–Дима, 27.09 как в дизайне. Повторный запуск импорта числа не удваивает.

## Шаги

1. Скопировать xlsx на сервер вне git, удалить после импорта.
2. Прогнать ту же команду импорта против боевого `DATABASE_URL`.
3. Выполнить проверочные SQL из задачи 019.
4. Глазами открыть в админке 27.09, 18.10, 25.10 и одну строку с пометкой расхождения, например 01.03.2026.
5. Убедиться, что 07.09.2025 в списке нет.

## Проверить

Цифры проверок записаны в комментарий к выкладке или в лог команды.
