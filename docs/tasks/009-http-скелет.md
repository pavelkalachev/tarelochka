# 009. HTTP-скелет

Срез: Каркас

Зависит от: 008

## Зачем

Админка и вебхук позже сядут на один роутер.

## Готово, когда

Процесс слушает порт из `HTTP_ADDR`. `GET /healthz` возвращает 200 и текст `ok`. Неизвестный путь возвращает 404.

## Шаги

1. Роутер стандартной библиотеки Go 1.22+.
2. Таймауты чтения и записи заголовков выставить явно.
3. Лог запроса: метод, путь, код, длительность. Тело запроса и токены не логировать.
4. `/healthz` не ходит в Telegram.

## Проверить

`curl -i localhost:порт/healthz` даёт 200.
