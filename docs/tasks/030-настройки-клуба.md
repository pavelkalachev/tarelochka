# 030. Настройки клуба

Срез: Админка

Зависит от: 014, 023

## Зачем

Цена студента и напоминание о долге должны меняться без деплоя.

## Готово, когда

Можно сохранить цену студента, выключить напоминание и поставить интервал 3 дня и время 12:00. Некорректный интервал 0 не сохраняется.

## Шаги

1. `GET/PUT /api/settings`.
2. Поля: цена студента, порог подсказки новичка, напоминание включено, число дней, время.
3. Подсказка под ценой: уже посчитанные тренировки не пересчитываются.
4. Экран одна колонка.

## Проверить

После PUT GET возвращает новые значения.
