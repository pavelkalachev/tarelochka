# 027. Список тренировок

Срез: Админка

Зависит от: 015, 023

## Зачем

Перенесённые вечера и будущие даты должны быть видны одним списком.

## Готово, когда

Список показывает дату, статус, сумму зала, пометку расхождения и число людей. Фильтр по сезону не обязателен: список с самой новой даты сверху, прокрутка.

## Шаги

1. `GET /api/sessions`.
2. Строка ведёт на страницу тренировки.
3. Пометка mismatch видна текстом, не только цветом.
4. На телефоне строка переносится, дата остаётся читаемой.

## Проверить

После импорта в списке 48 тренировок и нет 07.09.2025.
