# 003. Получить сервер

Срез: Подготовка

Зависит от: нет

## Зачем

Бот, админка и Postgres работают на одной машине.

## Готово, когда

Есть VPS с SSH-доступом по ключу, пользователь не root для приложения, открыты порты 22, 80 и 443. На машине стоят Docker и Docker Compose.

## Шаги

1. Выбрать одного провайдера с датацентром, от которого Челябинск отвечает быстро. Достаточно 1–2 ГБ RAM: один процесс Go и Postgres.
2. Создать сервер с Ubuntu LTS.
3. Зайти по SSH ключом. Вход по паролю выключить после проверки ключа.
4. Создать пользователя `app`. Дальше сервисы живут под ним.
5. Поставить Docker Engine и плагин Compose по инструкции Docker для этой версии Ubuntu.
6. Включить firewall: разрешить 22, 80, 443.
7. Записать IP и пользователя SSH в заметку запуска, не в git.

## Проверить

`ssh app@сервер docker compose version` печатает версию.
