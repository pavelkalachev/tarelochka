# Задачи

Идём по номерам внутри этапа. Следующий этап не начинаем, пока текущий не сошёлся. План поведения и стек: [design.md](../design.md). Схема опубликованной системы: [ARCHITECTURE.md](../ARCHITECTURE.md).

Одна задача — один результат. Секреты, xlsx таблицы и `.env` в git не кладём.

## Как идём

1. Разработка локально: база, API, админка и бот на своей машине. Боевого сервера и чата клуба нет.
2. Отладка на своём чате: отдельный тестовый бот и закрытая группа. Локальный процесс забирает обновления через long polling. Домен и вебхук для этого не нужны.
3. Тестирование: полный прогон недели на тестовом чате и локальной базе.
4. Отладка по результатам прогона, пока чеклист не проходит.
5. Публикация: сервер, домен, бот клуба, чат «Алтимат. Челябинск», перенос таблицы. Только после прогона.

Тестовый токен в локальный `.env`. Боевой токен только на сервере, и только на этапе публикации.
