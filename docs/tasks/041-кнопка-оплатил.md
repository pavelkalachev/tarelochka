# 041. Кнопка «Оплатил»

Срез: Чат

Зависит от: 040

## Зачем

Игрок заявляет оплату. Пара может нажать с любого из двух аккаунтов.

## Готово, когда

Нажатие Дениса или Вики создаёт одну pending-заявку на все неоплаченные доли пары. Второе нажатие новую заявку не создаёт. Чужой id получает всплывающую подсказку и не меняет сообщение. Сообщение в чате помечает строки «ждёт подтверждения».

## Шаги

1. По callback узнать user id и username. Найти человека так же, как голос.
2. Если человек не найден, answerCallbackQuery show_alert: «Не нашёл тебя в списке клуба». Заявку не создавать.
3. Найти платёжную группу: человек, его плательщик и все, кто платит через него. Для Вики группа — Денис и Вика.
4. В заявку входят только их unpaid-доли этой тренировки.
5. Если неоплаченных нет, подсказка «по этой тренировке долга нет».
6. Если pending-заявка группы уже есть, подсказка «заявка уже отправлена».
7. Иначе создать claim, перевести эти доли в claimed, запомнить, кто нажал.
8. Отредактировать текст debt message.
9. Ответить нажавшему toast «Заявку отправил».

## Проверить

Тест: Вика нажимает первой, Денис вторым, claim в базе один.
