# 031. Сводка по человеку

Срез: Админка

Зависит от: 015, 024

## Зачем

Таблицу заменяют в том числе вопросом «сколько человек должен за сезон».

## Готово, когда

На карточке человека видны число явок, начислено, оплачено и долг. Долг равен начислено минус оплачено. Нулевые доли новичка в начислено не добавляют сумму. 27.09 у Паши в оплаченное входит его 614.

## Шаги

1. Считать по shares: явка — строка share или attendance attended. Начислено — сумма amount где amount не null. Оплачено — сумма amount со статусом paid. Долг — разница.
2. Ниже список тренировок этого человека с суммой и статусом оплаты.
3. Помеченные mismatch тренировки в списке помечены, но из итогов не выкидываются: история перенесена как есть.
4. API `GET /api/people/{id}/balance`.

## Проверить

Цифры карточки Даниила включают его исторические 200 и не включают чужие доли.
