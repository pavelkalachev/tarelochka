# 018. Чтение xlsx таблицы

Срез: Данные

Зависит от: 017

## Зачем

Цвет оплаты есть только в xlsx. CSV его теряет.

## Готово, когда

Команда импорта читает локальный xlsx и печатает число строк, не записывая в базу. Файл xlsx не коммитится.

## Шаги

1. Положить выгрузку вне репозитория или в игнорируемый путь.
2. Прочитать оба листа. Шапка людей: строка 2, колонки F–X, 19 имён.
3. Даты в колонке B. Пустую дату пропустить.
4. Заливку ячейки доли: оплачено только если цвет ровно `#00FF00`. Условное форматирование колонки даты не считать оплатой.
5. Числа с запятой `444,4444444` разобрать как десятичные и отрезать до целых рублей вниз к уже показанному в ячейке виду 444. Не округлять их новым правилом вверх.
6. Плюс оставить плюсом до задачи правил.
7. Напечатать сводку: сколько строк с датой, сколько пустых, сколько плюсов, сколько зелёных.

## Проверить

Сводка по текущему файлу: 63 даты, 15 строк без состава и без суммы, плюсы только 27.09, 18.10 и 25.10.
