# 010. Каркас фронтенда

Срез: Каркас

Зависит от: 007

## Зачем

Админка на React 19, TypeScript, Tailwind и shadcn, с нормальной вёрсткой на ширине телефона.

## Готово, когда

`npm run dev` открывает пустую оболочку. `npm run build` проходит. На ширине 390px нет горизонтального скролла у пустой страницы.

## Шаги

1. В `web/` создать Vite-проект React + TypeScript.
2. Поставить React 19, если шаблон Vite отстал.
3. Поставить Tailwind и инициализировать shadcn/ui теми командами, которые актуальны на день задачи. Версии не выдумывать вручную.
4. Подключить шрифт и базовые цвета shadcn. Тёмная тема не обязательна.
5. Корневой layout: шапка с названием «Алтимат» и пустая область контента. Навигацию добавит задача 023.
6. В Go пока не встраивать статику. Это задача 045.

## Проверить

Сборка `web/dist` появляется. В ней нет секретов.
