# 045. Сборка одного сервиса

Срез: Публикация

Зависит от: 010, 009, 023, 050

## Зачем

Образ собирают и проверяют на машине разработчика. На сервер его выкладывает задача 046, после прогона на тестовом чате.

## Готово, когда

Образ содержит бинарник Go и `web/dist`. Локально `docker compose` поднимает `app` и `postgres`. `/healthz` на localhost отвечает 200. Боевой сервер на этом шаге не нужен.

## Шаги

1. Multi-stage Dockerfile: стадия node собирает `web/`, стадия go собирает сервер, в рантайм кладётся dist.
2. Go отдаёт файлы админки с диска и API под `/api`.
3. `docker-compose.yml`: app и postgres. Пароли из env-файла, файл не в git. Конфиг Caddy лежит рядом, но сертификат и публичный прокси включает задача 046 на сервере.
4. Volume postgres.
5. Перезапуск app не стирает базу.
6. Прогон на localhost. Токен в этом запуске по-прежнему тестовый, `TELEGRAM_WEBHOOK_URL` пуст.

## Проверить

`docker compose ps` на машине разработчика показывает app и postgres. Браузер открывает оболочку админки на localhost.
