# 045. Сборка одного сервиса

Срез: Запуск

Зависит от: 010, 009, 023

## Зачем

На сервер уезжает один процесс и одна база, как договорились.

## Готово, когда

Образ содержит бинарник Go и `web/dist`. Контейнер `app` и контейнер `postgres` поднимаются compose на сервере. `/healthz` с сервера отвечает 200.

## Шаги

1. Multi-stage Dockerfile: стадия node собирает `web/`, стадия go собирает сервер, в рантайм кладётся dist.
2. Go отдаёт файлы админки с диска и API под `/api`.
3. `docker-compose.yml` для сервера: app, postgres, caddy. Пароли из env-файла на сервере, файл не в git.
4. Volume postgres.
5. Перезапуск app не стирает базу.

## Проверить

`docker compose ps` показывает app и postgres. Браузер открывает оболочку админки по https.
