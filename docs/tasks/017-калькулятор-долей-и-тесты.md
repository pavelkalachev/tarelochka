# 017. Калькулятор долей и тесты

Срез: Данные

Зависит от: 015

## Зачем

Правило денег легко сломать. Его фиксируют тесты до UI и бота.

## Готово, когда

Пакет `internal/money` считает примеры из дизайна и не ходит в базу. `go test` зелёный.

## Шаги

1. Вход: сумма зала, список пришедших с типом, цена студента, id инвестора.
2. Студент получает ровно цену студента. Новичок получает 0. Обычные делят остаток.
3. Доля обычного = ceil(остаток / число обычных). Целые рубли.
4. Если остаток делится нацело, доплаты нет.
5. Если обычных нет или студенты суммарно больше зала, вернуть ошибку, доли не подставлять.
6. Если инвестор в составе, его доля помечена оплаченной через `investor`.
7. Тесты:
   - 4500, студент 200, 2 новичка, 6 обычных → обычные по 717, итог 4502.
   - Ровно делящийся остаток без лишних рублей.
   - Только студенты и новички → ошибка.
   - Студенты дороже зала → ошибка.
   - Инвестор среди обычных → его доля paid.
8. Этот пакет не пересчитывает исторические строки. Перенос пишет числа сам.

## Проверить

Тест на 717 рублей падает, если округление заменить на вниз.
