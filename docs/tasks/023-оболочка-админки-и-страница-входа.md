# 023. Оболочка админки и страница входа

Срез: Админка

Зависит от: 010, 022

## Зачем

С телефона и с компьютера видно, куда нажимать.

## Готово, когда

Невошедший пользователь видит текст «Откройте бота и нажмите Админка». Переход по `/?token=` потребляет ссылку и показывает имя организатора. На ширине 390px меню не расползается.

## Шаги

1. Маршруты React: `/` после входа, страница людей, залов, слотов, тренировок, настроек. Пока заглушки.
2. На ширине телефона навигация прячется в лист shadcn Sheet или в нижнюю панель. Выбрать один вариант и держать его везде.
3. `GET /api/me` через proxy Vite.
4. Страница consume читает token из query, вызывает API, убирает token из адресной строки.
5. Кнопка «Выйти» вызывает logout только этого браузера.
6. Компоненты кнопок, полей и таблиц брать из shadcn, не писать второй визуальный набор.

## Проверить

Вход, обновление страницы и выход проверены в узком окне браузера.
