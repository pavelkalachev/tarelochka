# 035. Публикация опроса

Срез: Бот

Зависит от: 034

## Зачем

После «Да» в чате появляется неанонимный опрос с двумя ответами.

## Готово, когда

Опрос один на тренировку. Повторный «Да» второй опрос не создаёт. Варианты ровно «Я буду» и «Я не буду». Голос не анонимный и его можно сменить.

## Шаги

1. Текст: «Тренировка в {день} в {время}. Кто придет?»
2. Bot API sendPoll: is_anonymous false, allows_multiple_answers false, options в этом порядке. type regular.
3. Сохранить telegram_poll_id и message_id в polls.
4. Статус тренировки polling.
5. Если запись polls уже есть, sendPoll не вызывать.

## Проверить

В тестовом чате или через мок клиента уходит один sendPoll.
