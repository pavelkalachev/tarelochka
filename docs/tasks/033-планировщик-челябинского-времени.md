# 033. Планировщик челябинского времени

Срез: Бот

Зависит от: 014, 032

## Зачем

Пятничные и субботние сообщения должны срабатывать в зоне клуба, даже если сервер в UTC.

## Готово, когда

Тест на фиксированных часах решает, какой момент слота наступил. Процесс раз в минуту смотрит слоты.

## Шаги

1. Пакет `internal/schedule`. Вход: сейчас в Asia/Yekaterinburg, слот, дата ближайшей тренировки.
2. Функция возвращает, какое действие пора: спросить про запуск, повторить вопрос, ранний итог, напоминание, субботний отчёт, зафиксировать состав. Или ничего.
3. Если опрос открыт позже раннего итога, ранний итог для этой даты больше не возвращается.
4. Тик раз в 30–60 секунд в том же процессе. Два тика в одну и ту же минуту одного действия не выполняют дважды: хранить `slot_fires(slot_id, session_date, action)` unique.
5. Тесты без сети: воскресенье 17:00 даёт snapshot. Пятница 12:00 даёт ask. Суббота 18:01 даёт report один раз.

## Проверить

Тест сдвига часов сервера на UTC не ломает пятницу 12:00 Челябинска.
