# 024. Экран людей

Срез: Админка

Зависит от: 021, 023

## Зачем

Ники, статусы, пары и депозит правятся до того, как бот начнёт узнавать нажатия.

## Готово, когда

Организатор меняет ник, статус, плательщика, телефон, пометку банка, роль и депозит. У Алисы и Саши виден счётчик 2 и подсказка, что до порога ещё есть явки. Порог 10 ещё не зажигает «пора сменить», потому что 2 < 10.

## Шаги

1. API `GET/PATCH /api/people`, `POST /api/people` для нового человека.
2. Список: имя, статус, ник, плательщик, долг можно отложить на задачу 031. На этом экране долг не обязателен.
3. Форма карточки на весь экран телефона, поля друг под другом.
4. Плательщик выбирается из других людей. Себя выбрать нельзя.
5. Роль организатора — переключатель. Последнего организатора снять нельзя, иначе в админку никто не войдёт. Проверить в локальной админке.
6. Депозит: число рублей. Пусто значит депозита нет, 0 значит депозит с нулём.

## Проверить

С телефона карточка Паши сохраняет телефон и пометку «сбер, т».
