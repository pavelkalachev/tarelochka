# 022. Вход по одноразовой ссылке

Срез: API

Зависит от: 016, 020, 021

## Зачем

Организатор открывает админку с компьютера и с телефона без пароля.

## Готово, когда

Ссылка из базы открывает сессию. Вторая попытка той же ссылки получает 401. Два устройства имеют две строки auth_sessions. Чужой ник ссылку не получает.

## Шаги

1. `POST /api/auth/magic` вызывается ботом изнутри процесса, не публичным интернетом. На этом шаге достаточно функции Go `IssueMagicLink(personID)`.
2. Токен случайный, в базе только хеш. Срок 10 минут. used_at ставится при успехе.
3. `POST /api/auth/consume` с токеном из query ставит cookie `session`. Cookie: Secure, HttpOnly, SameSite=Lax, срок 30 дней.
4. `POST /api/auth/logout` отзывает только текущую auth_sessions.
5. `GET /api/me` возвращает человека или 401.
6. Тест: consume дважды, второй раз отказ. Logout гасит только одну из двух сессий.

## Проверить

Тесты проходят на локальном Postgres.
