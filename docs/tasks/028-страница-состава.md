# 028. Страница состава

Срез: Админка

Зависит от: 015, 027

## Зачем

Организатор после игры отмечает, кто пришёл.

## Готово, когда

Можно снять человека, добавить человека клуба, подтвердить состав. До подтверждения блок долей написан «ещё не считали». Повторное открытие показывает те же галочки.

## Шаги

1. `GET /api/sessions/{id}` отдаёт явку и несопоставленных.
2. `PUT` состава: attended по людям клуба.
3. Несопоставленного можно связать с человеком. Это закроет и задачу узнавания голоса на уровне данных. UI связи на этой странице.
4. Кнопка «Состав подтверждён» пока только ставит roster_confirmed_at и status played, без расчёта. Расчёт подключит задача 039. Если нажать рано, кнопки расчёта ещё нет, это нормально для этого шага.
5. Кнопка «Пропуск» ставит status skip.
6. Фактическая сумма и инвестор редактируются на этой же странице до подтверждения. После подтверждения сумма тоже редактируется, но пересчёт долей будет в 039. Пока просто сохранить поля.

## Проверить

Снятая галочка переживает обновление страницы.
