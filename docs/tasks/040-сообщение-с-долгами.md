# 040. Сообщение с долгами

Срез: Чат

Зависит от: 039, 032

## Зачем

Сразу после расчёта чат видит, кому сколько переводить.

## Готово, когда

В чат уходит одно сообщение. В нём нет нулей новичков, нет доли инвестора и нет долей, которые закроет депозит на следующем шаге. Есть телефон инвестора. Повторный confirm правит это сообщение, а не шлёт второе.

## Шаги

1. После успешного confirm вызвать публикацию. Депозит применяет задача 043. На этом шаге депозит ещё не вычитает доли: сообщение строится из unpaid долей. Когда 043 появится, публикация должна идти после неё. Заложить порядок в коде: confirm → deposit → debt message. Пока deposit пустая функция.
2. Группировать по плательщику. Строка: «Денис — 1228 ₽ (614 за себя, 614 за Вику)».
3. Шапка: дата, сумма зала, «переводить {имя}, {телефон}, {пометка}».
4. Если инвестора или телефона нет, написать «телефон не указан» и не падать.
5. Сохранить message_id в debt_posts.
6. Кнопку «Оплатил» повесить уже здесь, callback `paid:{sessionID}`. Обработку нажатия делает задача 041. До неё answerCallbackQuery может отвечать «скоро», но лучше сразу сделать 041 следом и не выкатывать кнопку без обработчика.

## Проверить

Сообщение для пары Денис+Вика — одна строка на Дениса, не две независимые кнопки.
