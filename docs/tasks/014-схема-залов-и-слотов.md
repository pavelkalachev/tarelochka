# 014. Схема залов и слотов

Срез: Данные

Зависит от: 013

## Зачем

Минимум людей, цены и расписание настраиваются без правки кода.

## Готово, когда

Можно завести зал с двумя ценами и слот на воскресенье 17:00.

## Шаги

1. `gyms`: id, club_id, name, min_people int not null check > 0, active.
2. `gym_prices`: id, gym_id, label (например «час», «полтора часа»), price_rubles int check >= 0.
3. `slots`: id, club_id, gym_id, weekday 0–6, start_time time, valid_from date, valid_until date nullable, min_people_override int nullable. Роли дежурного и режима слота нет.
4. Часы автоматизации на слоте, все time not null: ask_time и ask_weekday, repeat_time и repeat_weekday, early_time и early_weekday, remind_time и remind_weekday, report_time и report_weekday. Значения по умолчанию вставить в комментарии миграции: пт 12:00, пт 18:00, пт 18:00, сб 12:00, сб 18:00.
5. `settings`: одна строка на клуб. student_price_rubles default 200, newcomer_prompt_after default 10, debt_reminder_enabled bool default true, debt_reminder_days int default 3 check > 0, debt_reminder_time time default 12:00.

## Проверить

Вставка слота с min_people_override 8 проходит. Отрицательная цена не проходит.
