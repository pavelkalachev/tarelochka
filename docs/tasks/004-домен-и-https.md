# 004. Домен и HTTPS

Срез: Подготовка

Зависит от: 003

## Зачем

Одноразовая ссылка входа открывается в браузере только по HTTPS. Вебхук Telegram тоже требует HTTPS.

## Готово, когда

Есть домен, A-запись на IP сервера. Сертификат выпускается и сам продлевается. `https://домен` открывается.

## Шаги

1. Зарегистрировать домен или поддомен, например `admin.пример.ru`.
2. Поставить A-запись на IP из задачи 003.
3. На сервере поставить Caddy или nginx с автоматическим сертификатом. Caddy проще: сам получает сертификат.
4. Пока приложения нет, Caddy может отдавать заглушку. На задаче 045 он начнёт проксировать на Go.
5. Проверить, что `https://домен` открывается с телефона, не только с ноутбука.
6. Записать публичный URL. Его же получит BotFather, если позже понадобится, но вход в админку идёт ссылкой из бота, виджет Telegram Login не используем.

## Проверить

С телефона в браузере открывается https-адрес без предупреждения о сертификате.
