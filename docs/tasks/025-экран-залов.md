# 025. Экран залов

Срез: Админка

Зависит от: 014, 023

## Зачем

Минимум и цены живут у зала, как договорились.

## Готово, когда

Можно создать зал, две цены и минимум 6 или 8. Список цен редактируется.

## Шаги

1. API залов и цен.
2. Экран: название, минимум, список «длительность / цена», кнопки добавить и удалить цену.
3. Пустое название не сохраняется.
4. На телефоне карточка зала одна колонка.

## Проверить

Зал с минимумом 8 сохраняется и снова открывается после перезагрузки.
