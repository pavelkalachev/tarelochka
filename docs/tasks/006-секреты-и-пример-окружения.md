# 006. Секреты и пример окружения

Срез: Подготовка

Зависит от: 001, 002, 003

## Зачем

Токен, id чата и пароль базы не должны попасть в git.

## Готово, когда

В репозитории есть `.env.example` без секретов и `.gitignore`, который прячет `.env`. Локальный `.env` заполнен и не виден в `git status`.

## Шаги

1. Добавить в `.gitignore`: `.env`, `*.xlsx`, выгрузки таблицы.
2. В `.env.example` перечислить переменные без значений-секретов:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
   - `DATABASE_URL`
   - `PUBLIC_BASE_URL`
   - `SESSION_TTL_HOURS=720`
   - `MAGIC_LINK_TTL_MINUTES=10`
   - `TZ=Asia/Yekaterinburg`
3. Рядом в комментарии написать, откуда берётся каждая переменная: BotFather, getUpdates, сервер, домен.
4. Создать локальный `.env` и подставить реальные значения на машине разработчика.

## Проверить

`git status` не показывает `.env`. В example нет токена.
