# 006. Секреты и пример окружения

Срез: Локальная разработка

Зависит от: 001, 002

## Зачем

Токен тестового бота, id своего чата и пароль локальной базы не должны попасть в git. Боевой токен и id чата клуба в этот файл не пишут.

## Готово, когда

В репозитории есть `.env.example` без секретов и `.gitignore`, который прячет `.env`. Локальный `.env` заполнен и не виден в `git status`.

## Шаги

1. Добавить в `.gitignore`: `.env`, `*.xlsx`, выгрузки таблицы.
2. В `.env.example` перечислить переменные без значений-секретов:
   - `TELEGRAM_BOT_TOKEN` — токен тестового бота
   - `TELEGRAM_CHAT_ID` — id своего тестового чата
   - `TELEGRAM_WEBHOOK_URL` — пусто, пока разработка локальная
   - `TELEGRAM_WEBHOOK_SECRET`
   - `DATABASE_URL` — локальный Postgres, схема `postgres://`, для Docker `sslmode=disable`
   - `PUBLIC_BASE_URL` — адрес локальной админки, например `http://localhost:8080`
   - `SESSION_TTL_HOURS=720`
   - `MAGIC_LINK_TTL_MINUTES=10`
   - `TZ=Asia/Yekaterinburg`
3. В комментарии написать, что боевые значения (токен бота клуба, id чата клуба, публичный https и URL вебхука) появляются только в окружении сервера на задаче 046. В пример и в локальный `.env` их не подставлять.
4. Создать локальный `.env` и подставить токен и id из задач 001 и 002.

## Проверить

`git status` не показывает `.env`. В example нет токена.
