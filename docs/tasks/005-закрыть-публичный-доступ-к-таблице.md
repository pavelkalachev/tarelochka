# 005. Закрыть публичный доступ к таблице

Срез: Публикация

Зависит от: нет

## Зачем

В колонке «Куда кидать» лежат телефоны. Таблица открывается по ссылке без входа. Это не выкладка бота: локальная разработка идёт из уже скачанного xlsx и ссылку не открывает. Закрыть доступ нужно до боевого переноса, задача 047. Раньше можно, на свой чат и локальную базу это не влияет.

## Готово, когда

По старой ссылке таблица больше не открывается у человека без доступа. У того, кто ведёт перенос, доступ на чтение или на выгрузку xlsx остаётся.

## Шаги

1. Открыть таблицу сезона под аккаунтом владельца. Ссылку и id в репозиторий не копировать.
2. Настройки доступа: выключить «все, у кого есть ссылка».
3. Оставить доступ конкретным людям клуба, которым таблица ещё нужна как архив на время переноса.
4. Скачать xlsx себе локально до закрытия, если выгрузка после закрытия станет неудобной. Файл с телефонами не коммитить.
5. Проверить в приватном окне браузера, что старая ссылка просит вход.

## Проверить

Приватное окно не показывает ячейки таблицы.
