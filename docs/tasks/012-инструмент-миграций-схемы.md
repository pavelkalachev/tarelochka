# 012. Инструмент миграций схемы

Срез: Данные

Зависит от: 008

## Зачем

Схема должна накатываться одинаково локально и на сервере.

## Готово, когда

`goose up` создаёт служебную таблицу goose. Повторный `up` ничего не меняет. `goose down` последней миграции откатывает её.

## Шаги

1. Подключить goose к `DATABASE_URL`.
2. Каталог `migrations/` с первым пустым SQL, который можно откатить.
3. Команда в README: `go run` или `make migrate`.
4. Миграции только SQL-файлами, без изменения схемы из кода приложения при старте.

## Проверить

Два подряд `up` завершаются без ошибки.
