# 007. Каркас репозитория

Срез: Каркас

Зависит от: 006

## Зачем

Один модуль Go и одно приложение React должны жить в предсказуемых папках.

## Готово, когда

`make test` и `npm run build` в `web/` проходят на пустом каркасе. Запуск описан в `README` через команды из `Makefile`, второй способ рядом не заводится.

## Шаги

1. В корне `go.mod` с модулем, например `github.com/pkalachev/tarelochka-bot` или путём, который совпадает с фактическим репозиторием.
2. Папки: `cmd/server` (точка входа), `internal/` (пока пустые пакеты `httpapi`, `bot`, `schedule`, `money`, `store`), `migrations/`, `web/`.
3. `cmd/server/main.go` читает окружение и пока только логирует, что процесс жив.
4. Не создавать второй сервис и не выносить бота в отдельный бинарник.

## Проверить

Из корня собирается один бинарник `server`.
