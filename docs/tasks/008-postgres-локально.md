# 008. Postgres локально

Срез: Каркас

Зависит от: 007

## Зачем

Схему и перенос таблицы нужно проверять на своей машине до сервера.

## Готово, когда

`docker compose up postgres` поднимает Postgres. Go-процесс подключается по `DATABASE_URL` из `.env` и пишет в лог, что соединение есть.

## Шаги

1. `docker-compose.yml` в корне: сервис `postgres`, образ официальный, порт 5432 на localhost, volume для данных, пользователь и пароль только из `.env`.
2. База, например `tarelochka`.
3. В `cmd/server` на старте открыть пул `pgxpool` и выполнить `select 1`.
4. Описать в README одну команду подъёма базы.

## Проверить

После перезапуска compose данные volume на месте. `select 1` в логе успешен.
