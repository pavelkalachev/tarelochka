# 008. Postgres локально

Срез: Каркас

Зависит от: 007

## Зачем

Схему и перенос таблицы нужно проверять на своей машине до сервера.

## Готово, когда

`make db` поднимает Postgres и дожидается готовности. Go-процесс подключается по `DATABASE_URL` из `.env` и пишет в лог, что соединение есть.

## Шаги

1. `docker-compose.yml` в корне: сервис с именем `postgres`, образ официальный, порт 5432 на localhost, volume для данных, пользователь и пароль только из `.env`. Healthcheck, чтобы `make db` дождался приёма соединений.
2. База, например `tarelochka`.
3. В `cmd/server` на старте открыть пул `pgxpool` и выполнить `select 1`.
4. В README одна команда подъёма базы: `make db`. Остановка — `make db-down`, логи — `make db-logs`.

## Проверить

После перезапуска compose данные volume на месте. `select 1` в логе успешен.
