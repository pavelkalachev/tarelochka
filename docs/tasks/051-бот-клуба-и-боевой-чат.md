# 051. Бот клуба и боевой чат

Срез: Публикация

Зависит от: 050

## Зачем

В чат «Алтимат. Челябинск» бот попадает после того, как прогон на тестовом чате прошёл. Это другой бот, не тот, которым отлаживали локально.

## Готово, когда

Есть боевой бот и его токен. Он добавлен в чат клуба и может писать. Id чата клуба записан только в окружение сервера. Тестовый бот в чате клуба не состоит. Отладочных сообщений в чате клуба нет.

## Шаги

1. В @BotFather создать нового бота. Имя, которое видят люди клуба. Username заканчивается на `bot`. Токен не совпадает с тестовым из задачи 001.
2. `/setdescription`: короткая фраза, что бот собирает явку и долги тренировок.
3. `/setjoingroups` Enable. `/setprivacy` Disable, как у тестового бота.
4. Добавить этого бота в чат «Алтимат. Челябинск». Выдать право писать сообщения. Право закреплять не требуется.
5. Узнать id чата клуба. Записать его и боевой токен в окружение сервера, не в git и не в локальный `.env` разработки.
6. Не писать в чат клуба пробный опрос и не звать long polling этим токеном с машины разработчика.

## Проверить

В чате клуба есть боевой бот и нет тестового. Локальный `.env` по-прежнему содержит только тестовый токен и id тестового чата.
