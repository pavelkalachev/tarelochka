# 036. Приём голосов

Срез: Бот

Зависит от: 020, 035

## Зачем

Состав строится из «Я буду», люди узнаются по никам, которые внесли заранее.

## Готово, когда

Голос известного ника пишет attendance. Смена голоса на «Я не буду» снимает coming. Неизвестный username создаёт несопоставленную строку и не создаёт долю.

## Шаги

1. Обрабатывать update poll_answer. option 0 = буду, option 1 = не буду. Пустой option_ids значит голос снят.
2. Найти человека по telegram_user_id, иначе по username без учёта регистра.
3. При первом совпадении username записать telegram_user_id.
4. Неизвестный: attendance с unmatched_label из first_name и username. person_id пустой.
5. Пока опрос открыт, эти строки черновик. В момент snapshot они станут исходным составом. До snapshot страница тренировки может их показывать как предварительные.
6. Не создавать shares на этом шаге.

## Проверить

Тест: смена голоса с «буду» на «не буду» оставляет coming=false.
