# 049. Кнопка «Админка» в личном чате

Срез: Локальная разработка

Зависит от: 022, 032, 020

## Зачем

Организатор получает ссылку так, как описано в дизайне, а не через ручную вставку токена в базу. Проверка идёт тестовым ботом на localhost.

## Готово, когда

Нажатие «Админка» организатором в личке тестового бота присылает рабочую ссылку на локальную админку. Нажатие человеком без роли присылает отказ и не создаёт magic link. Ссылка не появляется в тестовой группе. Чат клуба не используется.

## Шаги

1. После `/start` в личке показать reply-кнопку «Админка».
2. По username или id найти человека. Нет роли — ответ «Нет доступа» без ссылки.
3. Есть роль — IssueMagicLink и отправить URL `PUBLIC_BASE_URL/?token=...` только в этот private chat. Локально `PUBLIC_BASE_URL` указывает на localhost.
4. Игнорировать эту кнопку, если chat id равен id группы.
5. Проверить с двух устройств два разных token.

## Проверить

В логе тестовой группы нет текста ссылки. В личке организатора ссылка открывает локальную админку.
